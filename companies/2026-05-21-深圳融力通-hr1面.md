❓ **问题 1：Vue2 和 Vue3 的差异**
**问题描述:** 从底层实现、性能优化、开发体验等角度，简述 Vue2 和 Vue3 的主要区别。
**我的解答:**
Vue2 和 Vue3 的差异主要体现在以下几个方面：

1. **响应式原理不同**：
   Vue2 使用 `Object.defineProperty` 实现数据劫持，需要递归遍历对象属性，因此对于对象新增属性和数组下标修改监听存在局限。
   Vue3 使用 `Proxy` 实现响应式代理，能够直接监听对象整体，天然支持对象新增/删除属性、数组索引变化，响应式能力更完整。
2. **性能更好**：
   Vue3 在源码层面对虚拟 DOM 和编译阶段做了更多优化，比如 **静态提升**、**Patch Flag**、**Tree Shaking** 等，所以在首屏渲染和更新性能上通常优于 Vue2。
3. **API 设计不同**：
   Vue2 主要使用 **Options API**，代码按 `data`、`methods`、`computed` 等配置项拆分。
   Vue3 除了兼容 Options API，还新增了 **Composition API**，可以把同一业务逻辑聚合在一起，提升复杂组件的可维护性和复用性。
4. **生命周期有变化**：
   Vue3 的生命周期命名更统一，比如：
   `beforeDestroy` 改为 `beforeUnmount`，
   `destroyed` 改为 `unmounted`。
5. **生态与新特性**：
   Vue3 更好支持 `TypeScript`，并提供 `Fragment`、`Teleport`、`Suspense` 等新特性，在大型项目和工程化场景下更有优势。

**总结：**
如果是中小型项目，Vue2 上手快、生态成熟；如果是新项目或复杂项目，Vue3 在性能、维护性和扩展性上更有优势。
**知识点标签:** #Vue #Vue2 #Vue3 #响应式原理 #前端框架

❓ **问题 2：跨域问题如何解决**
**问题描述:** 浏览器同源策略导致接口请求被拦截时，前端开发和生产环境一般怎么处理？
**我的解答:**
跨域本质上是浏览器的**同源策略**限制，常见解决方案有以下几种：

1. **CORS**：
   这是最主流的方式。由后端在响应头中配置 `Access-Control-Allow-Origin`、`Access-Control-Allow-Methods`、`Access-Control-Allow-Headers` 等字段，允许指定来源访问资源。
2. **开发环境代理**：
   在本地开发时，常通过 `Vite`、`Webpack` 的代理配置解决跨域。前端请求本地开发服务器，由本地服务器转发到真实后端，因为服务端转发不受浏览器同源策略限制。
3. **Nginx 反向代理**：
   生产环境常用方案。前端统一请求同源网关地址，由 Nginx 转发到后端服务，这样浏览器看来仍然是同源请求。
4. **JSONP**：
   这是一种较老的方案，利用 `<script>` 标签不受同源策略限制来获取数据，但只支持 `GET` 请求，现在使用较少。

**实际开发中**：
我一般会区分场景：
开发环境优先用 `proxy`，
线上环境优先通过 **CORS** 或 **Nginx 反向代理** 解决。
**知识点标签:** #网络协议 #跨域 #CORS #Nginx #前端工程化

❓ **问题 3：CSS 的盒模型**
**问题描述:** 什么是 CSS 盒模型？标准盒模型和 IE 盒模型有什么区别？
**我的解答:**
CSS 盒模型可以理解为，页面中的每个元素都会被看成一个矩形盒子，它由四部分组成：

1. **content**：内容区域
2. **padding**：内边距
3. **border**：边框
4. **margin**：外边距

盒模型主要分为两种：

1. **标准盒模型（content-box）**：
   元素设置的 `width` 和 `height` 只包含 **content**，不包含 `padding` 和 `border`。
   也就是说，元素最终实际占据的宽高是：
   `width + padding + border`
2. **IE 盒模型（border-box）**：
   元素设置的 `width` 和 `height` 包含 **content + padding + border**。
   这样在布局时更方便控制整体尺寸，所以现在开发中比较常用。

可以通过下面这个属性切换盒模型：

```css
box-sizing: content-box; /* 标准盒模型 */
box-sizing: border-box;  /* IE盒模型 */
```

**实际开发中**：
我一般会全局设置：

```css
* {
  box-sizing: border-box;
}
```

这样在做页面布局时，元素宽高更容易计算，能减少很多样式问题。
**知识点标签:** #CSS #盒模型 #布局 #前端基础
